• API 키 없이 제미나이(Gemini) 앱 바로 이용: 별도의 키 발급 없이 내 관상 캐릭터와 4문답 결과가 담긴 맞춤형 프롬프트를 자동 복사하여 제미나이 앱(gemini.google.com/app)에서 바로 AI 심층 리딩을 받을 수 있습니다.
• 철저한 무사진(텍스트 전용) 원칙: 제미나이 앱으로 전달되는 프롬프트에는 얼굴 사진·영상·랜드마크가 절대 포함되지 않으며 오직 관상 캐릭터명과 문답 텍스트만 담깁니다.
• 답변 교지 적용 지원: 제미나이 앱에서 받은 답변을 아래 입력칸에 붙여넣으면 이 화면의 한지 두루마리(타자 효과음 · 인쇄/PDF 저장)에 그대로 반영됩니다.

✨ 제미나이(Gemini) 앱으로 AI 관상 리딩 이용 방법 (4단계 안내)

별도의 API 키 발급 없이 평소 쓰시는 제미나이(Gemini) 앱 또는 웹(gemini.google.com/app)으로 바로 심층 관상 리딩을 받아 보실 수 있습니다.

1단계: 프롬프트 복사 후 제미나이 앱 열기
결과 화면에서 고민 키워드를 적은 뒤 [🚀 프롬프트 복사 후 제미나이(Gemini) 앱 열기] 버튼을 누르면 내 관상 캐릭터와 4문답 내용이 자동 복사되며 제미나이 앱이 열립니다.
2단계: 제미나이 앱 로그인
열리는 제미나이 앱(또는 gemini.google.com 웹페이지)에서 평소 사용하시는 Google 계정으로 로그인합니다.
3단계: 채팅창에 붙여넣기 후 전송
제미나이 대화 입력창을 길게 누르거나 붙여넣기(Ctrl+V / ⌘+V)를 하여 복사된 관상 질문을 입력하고 전송합니다.
4단계: 답변 감상 및 한지 교지 적용
제미나이 앱에서 바로 읽으시거나, 답변을 복사해 관상 연구소의 [3. 제미나이 답변 붙여넣기] 칸에 넣고 적용하면 타자 효과음과 함께 PDF 인쇄·저장을 하실 수 있습니다.
🔑 (참고) 고급 설정용 Google AI Studio API 키 발급 4단계 보기
1단계: aistudio.google.com 접속 → 2단계: Google 계정 로그인 → 3단계: Get API key / Create API key로 키 만들기 → 4단계: 고급 설정 입력창에 붙여넣기 후 생성.
