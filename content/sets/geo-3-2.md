# 상자 1 · 위치벡터와 내분점
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 내분점의 위치벡터

## 하
문제: 두 점 A, B의 위치벡터를 각각 {a}, {b}라 할 때, 벡터 [AB]를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: -a+b
풀이: [AB] = [OB] − [OA] = {b} − {a}

## 중
문제: 두 점 A, B의 위치벡터를 각각 {a}, {b}라 할 때, 선분 AB를 2 : 1로 내분하는 점 P의 위치벡터 {p}를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: 1/3a+2/3b
풀이: m : n으로 내분하는 점은 (m{b} + n{a})/(m + n)이에요. (2{b} + {a})/3 = (1/3){a} + (2/3){b}

## 상
문제: 삼각형 ABC의 세 꼭짓점 A, B, C의 위치벡터를 각각 {a}, {b}, {c}, 무게중심 G의 위치벡터를 {g}라 하자. <보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. {g} = ({a} + {b} + {c})/3\nㄴ. [GA] + [GB] + [GC] = $\vv{0}$\nㄷ. 선분 AB의 중점 M의 위치벡터는 ({a} − {b})/2이다.
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 2
풀이: ㄱ. 무게중심은 중선을 2 : 1로 내분하므로 참. ㄴ. ({a} − {g}) + ({b} − {g}) + ({c} − {g}) = {a} + {b} + {c} − 3{g} = $\vv{0}$ (참). ㄷ. 중점은 ({a} + {b})/2이므로 거짓.

# 상자 2 · 평면벡터의 크기
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 두 평면벡터가 같을 조건과 크기

## 하
문제: 벡터 {a} = (3, −4)의 크기 |{a}|를 구하시오.
답 형식: 숫자
정답: 5
풀이: |{a}| = √(3² + (−4)²) = 5

## 중
문제: 두 점 A(1, −2), B(7, 6)에 대하여 |[AB]|를 구하시오.
답 형식: 숫자
정답: 10
풀이: [AB] = (7 − 1, 6 − (−2)) = (6, 8)이므로 |[AB]| = √(36 + 64) = 10

## 상
문제: 두 벡터 {a} = (2, 1), {b} = (−1, 3)에 대하여 |{a} + t{b}|의 최솟값을 구하시오. (단, t는 실수)
답 형식: 숫자
정답: 7√10/10
풀이: {a} + t{b} = (2 − t, 1 + 3t), |{a} + t{b}|² = 10t² + 2t + 5 = 10(t + 1/10)² + 49/10. 최솟값은 √(49/10) = 7√10/10

# 상자 3 · 성분에 의한 연산
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 평면벡터의 성분에 의한 연산

## 하
문제: 두 벡터 {a} = (2, −1), {b} = (1, 3)에 대하여 벡터 2{a} − {b}의 x성분과 y성분의 합을 구하시오.
답 형식: 숫자
정답: -2
풀이: 2{a} − {b} = (4 − 1, −2 − 3) = (3, −5)이므로 3 + (−5) = −2

## 중
문제: 세 벡터 {a} = (1, 2), {b} = (2, −1), {c} = (4, 3)에 대하여 {c} = x{a} + y{b}를 만족시키는 두 실수 x, y의 합 x + y를 구하시오.
답 형식: 숫자
정답: 3
풀이: x{a} + y{b} = (x + 2y, 2x − y) = (4, 3)에서 x + 2y = 4, 2x − y = 3. 연립하면 x = 2, y = 1

## 상
문제: 두 벡터 {a} = (m + 1, 3), {b} = (2, n − 1)이 서로 같을 때, <보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. m = 1\nㄴ. |{a}| = √13\nㄷ. {a} + {b} = (4, 6)
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 5
풀이: 대응하는 성분이 같으므로 m + 1 = 2, n − 1 = 3에서 m = 1, n = 4. {a} = (2, 3)이므로 |{a}| = √13, {a} + {b} = 2{a} = (4, 6). 모두 참.

# 상자 4 · 공간벡터의 성분
- 방: 2
- 협업: 아니오
- 그림: 없음
- 개념: 공간벡터의 성분과 크기

## 하
문제: 벡터 {a} = (1, −2, 2)의 크기 |{a}|를 구하시오.
답 형식: 숫자
정답: 3
풀이: |{a}| = √(1 + 4 + 4) = 3

## 중
문제: 좌표공간의 두 점 A(1, 0, 2), B(4, 2, 8)에 대하여 |[AB]|를 구하시오.
답 형식: 숫자
정답: 7
풀이: [AB] = (3, 2, 6)이므로 |[AB]| = √(9 + 4 + 36) = 7

## 상
문제: 세 벡터 {a} = (1, 2, −1), {b} = (2, −1, 3), {c} = (5, 0, 5)에 대하여 {c} = x{a} + y{b}를 만족시키는 두 실수 x, y의 곱 xy를 구하시오.
답 형식: 숫자
정답: 2
풀이: (x + 2y, 2x − y, −x + 3y) = (5, 0, 5). 둘째 식에서 y = 2x, 첫째 식에 넣으면 x = 1, y = 2이고 셋째 식 −1 + 6 = 5도 맞아요. xy = 2

# 상자 5 · 성분으로 본 평행 조건
- 방: 2
- 협업: 아니오
- 그림: 없음
- 개념: 성분으로 나타낸 평행 조건

## 하
문제: 두 벡터 {a} = (2, 3), {b} = (4, k)가 서로 평행할 때, 실수 k의 값을 구하시오.
답 형식: 숫자
정답: 6
풀이: {b} = 2{a}여야 하므로 k = 6

## 중
문제: 두 벡터 {a} = (1, −2, 3), {b} = (2, m, n)이 서로 평행할 때, m + n의 값을 구하시오.
답 형식: 숫자
정답: 2
풀이: {b} = 2{a}이므로 m = −4, n = 6, m + n = 2

## 상
문제: 두 벡터 {a} = (1, 2), {b} = (3, −1)에 대하여 두 벡터 {a} + 2{b}와 k{a} + {b}가 서로 평행할 때, 실수 k의 값을 구하시오.
답 형식: 숫자
정답: 1/2
풀이: {a} + 2{b} = (7, 0), k{a} + {b} = (k + 3, 2k − 1). (7, 0)과 평행하려면 y성분이 0이어야 하므로 2k − 1 = 0, k = 1/2

# 상자 6 · 내적의 뜻
- 방: 3
- 협업: 예
- 그림: 없음
- 개념: 내적의 뜻 (성분)

## 하
문제: 두 벡터 {a} = (3, 1), {b} = (2, −4)의 내적 {a}·{b}를 구하시오.
답 형식: 숫자
정답: 2
풀이: {a}·{b} = 3 × 2 + 1 × (−4) = 2

## 중
문제: 두 벡터 {a} = (1, −2, 2), {b} = (3, 0, −1)의 내적 {a}·{b}를 구하시오.
답 형식: 숫자
정답: 1
풀이: {a}·{b} = 3 + 0 − 2 = 1

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 채팅으로 조건을 알려 주고 함께 푸세요. 두 벡터 {a}, {b}가 두 조건을 모두 만족시킬 때, {a}·{b}의 값을 구하시오.
조건 ㉠: |{a}| = 3, |{b}| = 2
조건 ㉡: |{a} − {b}| = √7
답 형식: 숫자
정답: 3
풀이: |{a} − {b}|² = |{a}|² − 2{a}·{b} + |{b}|²이므로 7 = 9 − 2{a}·{b} + 4, {a}·{b} = 3

# 상자 7 · 두 벡터가 이루는 각
- 방: 3
- 협업: 예
- 그림: 없음
- 개념: 두 벡터가 이루는 각과 내적

## 하
문제: |{a}| = 2, |{b}| = 3이고 두 벡터 {a}, {b}가 이루는 각의 크기가 60°일 때, {a}·{b}를 구하시오.
답 형식: 숫자
정답: 3
풀이: {a}·{b} = |{a}||{b}|cos 60° = 2 × 3 × 1/2 = 3

## 중
문제: 두 벡터 {a} = (1, 1), {b} = (0, 2)가 이루는 각의 크기 θ를 구하시오. (도 단위의 수로 답하시오. 예: 30)
답 형식: 숫자
정답: 45
풀이: cos θ = {a}·{b} / (|{a}||{b}|) = 2 / (√2 × 2) = √2/2이므로 θ = 45°

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 두 조건을 모두 만족시키는 양수 x의 값을 구하시오.
조건 ㉠: 두 벡터 {a} = (1, 1, 0), {b} = (1, 0, x)
조건 ㉡: 두 벡터 {a}, {b}가 이루는 각의 크기는 60°이다.
답 형식: 숫자
정답: 1
풀이: cos 60° = {a}·{b} / (|{a}||{b}|) = 1 / (√2 × √(1 + x²)) = 1/2에서 √(1 + x²) = √2, x² = 1. x > 0이므로 x = 1

# 상자 8 · 벡터의 수직
- 방: 4
- 협업: 예
- 그림: 없음
- 개념: 벡터의 수직

## 하
문제: 두 벡터 {a} = (2, −1), {b} = (k, 4)가 서로 수직일 때, 실수 k의 값을 구하시오.
답 형식: 숫자
정답: 2
풀이: {a}·{b} = 2k − 4 = 0이므로 k = 2

## 중
문제: 두 벡터 {a} = (1, 2, −1), {b} = (3, k, 5)가 서로 수직일 때, 실수 k의 값을 구하시오.
답 형식: 숫자
정답: 1
풀이: {a}·{b} = 3 + 2k − 5 = 0이므로 k = 1

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 두 조건을 모두 만족시키는 실수 t의 값을 구하시오.
조건 ㉠: {a} = (1, 2), {b} = (2, −1)
조건 ㉡: 두 벡터 {a} + t{b}와 {a} − {b}는 서로 수직이다.
답 형식: 숫자
정답: 1
풀이: {a} + t{b} = (1 + 2t, 2 − t), {a} − {b} = (−1, 3). 내적 −(1 + 2t) + 3(2 − t) = 5 − 5t = 0이므로 t = 1

# 상자 9 · 도형과 내적
- 방: 4
- 협업: 예
- 그림: 없음
- 개념: 내적의 성질

## 하
문제: AB = 3, BC = 4인 직사각형 ABCD에서 [CD]·[CA]를 구하시오.
답 형식: 숫자
정답: 9
풀이: 두 벡터가 이루는 각을 θ라 하면 cos θ = CD/CA = 3/5. [CD]·[CA] = 3 × 5 × 3/5 = 9

## 중
문제: AB = 1, AD = 2, AE = 2인 직육면체 ABCD-EFGH에서 두 벡터 [AG]와 [DF]가 이루는 각의 크기를 θ라 할 때, cos θ의 값을 구하시오.
답 형식: 숫자
정답: 1/9
풀이: A를 원점, B(1, 0, 0), D(0, 2, 0), E(0, 0, 2)로 놓으면 [AG] = (1, 2, 2), [DF] = (1, −2, 2). 내적 1 − 4 + 4 = 1, 크기는 각각 3이므로 cos θ = 1/9

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 두 조건을 모두 이용하여 [CA]·[CP]의 값을 구하시오. (단, 이 값은 점 P의 위치에 관계없이 일정하다.)
조건 ㉠: AB = √3, BC = 3인 직사각형 ABCD가 있다.
조건 ㉡: 변 AD를 한 변으로 하는 정삼각형 EAD를 직사각형의 바깥쪽에 그리고, 점 P는 선분 AE 위를 움직인다.
답 형식: 숫자
정답: 12
풀이: A(0, 0), D(3, 0), B(0, −√3), C(3, −√3), E(3/2, 3√3/2)로 놓고 P = s(3/2, 3√3/2)라 하면 [CA] = (−3, √3), [CP] = (3s/2 − 3, 3√3s/2 + √3). 내적 = −9s/2 + 9 + 9s/2 + 3 = 12로 s에 관계없이 일정해요.

# 핵심 카드 · 위치벡터
- 비석: 1
요약: 한 점 O를 시점으로 하는 벡터 [OA]를 점 O에 대한 점 A의 위치벡터라고 해요.
- 점과 위치벡터는 일대일로 대응해요. 좌표에서는 보통 원점 O를 시점으로 잡아요.
- 두 점 A, B의 위치벡터를 {a}, {b}라 하면 [AB] = {b} − {a}
- 이정표처럼 출발점을 하나로 모으면 방향과 거리를 비교하기 쉬워요.

# 핵심 카드 · 내분점의 위치벡터
- 비석: 2
요약: 선분 AB를 m : n으로 내분하는 점 P의 위치벡터는 {p} = (m{b} + n{a})/(m + n)
- 특히 중점 M의 위치벡터는 {m} = ({a} + {b})/2
- 세 점 A, P, B가 한 직선 위에 있으면 [AP] = k[AB]인 실수 k가 있어요.
- 베지에 곡선은 내분점을 반복해서 부드러운 곡선을 만들어요.

# 핵심 카드 · 무게중심의 위치벡터
- 비석: 3
요약: 삼각형 ABC의 무게중심 G의 위치벡터는 {g} = ({a} + {b} + {c})/3
- 무게중심은 중선을 꼭짓점으로부터 2 : 1로 내분해요.
- [GA] + [GB] + [GC] = $\vv{0}$

# 핵심 카드 · 평면벡터의 성분
- 비석: 4
요약: {a} = a₁{e₁} + a₂{e₂}를 {a} = (a₁, a₂)로 나타내요.
- {e₁} = (1, 0), {e₂} = (0, 1)은 x축, y축 방향의 단위벡터예요.
- a₁을 x성분, a₂를 y성분이라고 해요.
- 점 A(a₁, a₂)의 위치벡터는 (a₁, a₂)예요.

# 핵심 카드 · 두 평면벡터가 같을 조건과 크기
- 비석: 5
요약: (a₁, a₂) = (b₁, b₂) ⟺ a₁ = b₁, a₂ = b₂
- |{a}| = √(a₁² + a₂²)
- 두 점 A, B에 대하여 [AB] = (b₁ − a₁, b₂ − a₂), |[AB]|는 두 점 사이의 거리

# 핵심 카드 · 평면벡터의 성분에 의한 연산
- 비석: 6
요약: 성분끼리 더하고 빼고, 실수배는 각 성분에 곱해요.
- {a} ± {b} = (a₁ ± b₁, a₂ ± b₂)
- k{a} = (ka₁, ka₂)
- {c} = x{a} + y{b}를 성분으로 쓰면 x, y에 대한 연립방정식이 돼요.

# 핵심 카드 · 공간벡터의 성분과 크기
- 비석: 7
요약: 공간에서는 {a} = (a₁, a₂, a₃) — x, y, z성분 세 개로 나타내요.
- {e₁} = (1, 0, 0), {e₂} = (0, 1, 0), {e₃} = (0, 0, 1)
- |{a}| = √(a₁² + a₂² + a₃²)
- 같을 조건, 덧셈·뺄셈·실수배도 평면과 같은 방법으로 성분마다 계산해요.

# 핵심 카드 · 성분으로 나타낸 평행 조건
- 비석: 8
요약: {a} ∥ {b} ⟺ {b} = k{a} — 대응하는 성분의 비가 같아요.
- 평면: (b₁, b₂) = (ka₁, ka₂)
- 공간: (b₁, b₂, b₃) = (ka₁, ka₂, ka₃)
- 영벡터가 아닌 두 벡터에서 k ≠ 0이에요.

# 핵심 카드 · 내적의 뜻 (성분)
- 비석: 9
요약: {a}·{b} = a₁b₁ + a₂b₂ (공간에서는 + a₃b₃까지) — 내적은 벡터가 아니라 실수예요.
- {a}·{a} = |{a}|²
- 두 제품의 (단가)·(판매 수량)을 곱해 더하면 판매액의 합 — 내적과 같은 계산이에요.

# 핵심 카드 · 내적의 성질
- 비석: 10
요약: 내적은 교환법칙과 분배법칙이 성립해요.
- {a}·{b} = {b}·{a}
- {a}·({b} + {c}) = {a}·{b} + {a}·{c}
- (k{a})·{b} = k({a}·{b})
- |{a} ± {b}|² = |{a}|² ± 2{a}·{b} + |{b}|²

# 핵심 카드 · 두 벡터가 이루는 각과 내적
- 비석: 11
요약: 이루는 각의 크기가 θ이면 {a}·{b} = |{a}||{b}|cos θ (0° ≤ θ ≤ 180°)
- cos θ = {a}·{b} / (|{a}||{b}|) = (a₁b₁ + a₂b₂) / (√(a₁² + a₂²)√(b₁² + b₂²))
- {a}·{b} > 0이면 예각, = 0이면 직각, < 0이면 둔각
- 힘이 한 일 = (힘)·(이동한 변위)

# 핵심 카드 · 벡터의 수직
- 비석: 12
요약: 영벡터가 아닌 두 벡터에 대하여 {a} ⊥ {b} ⟺ {a}·{b} = 0
- 성분으로 쓰면 a₁b₁ + a₂b₂ = 0 (공간에서는 + a₃b₃ = 0)
- 꼬인 위치에 있는 두 모서리가 수직인지도 내적으로 확인할 수 있어요.
