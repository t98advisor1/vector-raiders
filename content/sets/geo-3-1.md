# 상자 1 · 벡터의 크기
- 방: 1
- 협업: 아니오
- 그림: cuboid
- 개념: 벡터의 뜻과 크기

## 하
문제: 한 모서리의 길이가 2인 정육면체 ABCD-EFGH에서 벡터 [EG]의 크기 |[EG]|를 구하시오.
답 형식: 숫자
정답: 2√2
풀이: [EG]는 밑면(정사각형)의 대각선이에요. |[EG]| = √(2² + 2²) = 2√2

## 중
문제: 한 모서리의 길이가 2인 정육면체 ABCD-EFGH에서 벡터 [DF]의 크기 |[DF]|를 구하시오.
답 형식: 숫자
정답: 2√3
풀이: [DF]는 정육면체의 대각선이에요. |[DF]| = √(2² + 2² + 2²) = 2√3

## 상
문제: 세 모서리의 길이가 AB = 3, AD = 4, AE = 12인 직육면체 ABCD-EFGH에 대하여 <보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. |[AC]| = 5\nㄴ. |[AG]| = 13\nㄷ. |[EG]| = |[AG]| − |[AE]|
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 2
풀이: ㄱ. √(3²+4²) = 5 (참) ㄴ. √(3²+4²+12²) = 13 (참) ㄷ. |[EG]| = 5이지만 13 − 12 = 1이므로 거짓. 벡터의 크기는 그냥 빼서 구할 수 없어요.

# 상자 2 · 서로 같은 벡터
- 방: 1
- 협업: 아니오
- 그림: hex
- 개념: 서로 같은 벡터

## 하
문제: 오른쪽 그림과 같은 정육각형 ABCDEF에서 세 대각선의 교점을 O라 하자. 벡터 [AB]와 같은 벡터를 보기에서 모두 고르시오.
답 형식: 고르기
보기: FO, OC, ED, BC, EF, BO, OD
정답: FO, OC, ED
풀이: 크기와 방향이 모두 같아야 같은 벡터예요. [AB]를 평행이동해 꼭짓점이나 O에 딱 겹치는 것을 찾아요.

## 중
문제: 정육각형 ABCDEF에서 세 대각선의 교점을 O라 하자. 벡터 [AB]와 크기는 같지만 방향이 반대인 벡터를 보기에서 모두 고르시오.
답 형식: 고르기
보기: BA, OF, CO, DE, AF, OB, EF
정답: BA, OF, CO, DE
풀이: 크기가 같고 방향이 반대인 벡터는 −[AB] = [BA]와 같은 벡터예요. [BA]를 평행이동한 [OF], [CO], [DE]도 모두 답이에요.

## 상
문제: 정육각형 ABCDEF에서 세 대각선의 교점을 O라 하자. <보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. [AB] + [AF] = [AO]\nㄴ. [AC] + [AE] = 3[AO]\nㄷ. |[AB] + [BC] + [CD]| = |[AB]| + |[BC]| + |[CD]|
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 2
풀이: ㄱ. 평행사변형 ABOF에서 참. ㄴ. [AC] = [AO] + [OC], [AE] = [AO] + [OE]이고 [OC] + [OE] = [AO]이므로 참. ㄷ. 왼쪽은 |[AD]| = 2(한 변 1일 때), 오른쪽은 3이므로 거짓.

# 상자 3 · 벡터의 덧셈과 연산 법칙
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 벡터의 덧셈에 대한 연산 법칙

## 하
문제: 네 점 A, B, C, D에 대하여 [AB] + [BC] + [CD]와 같은 벡터를 보기에서 고르시오.
답 형식: 고르기
보기: AC, AD, BD, DA, CA
정답: AD
풀이: 앞 벡터의 종점과 다음 벡터의 시점이 이어지면 처음 시점에서 마지막 종점으로 가는 벡터가 돼요.

## 중
문제: 네 점 A, B, C, D에 대하여 [AC] + [BA] + [DB]와 같은 벡터를 보기에서 고르시오.
답 형식: 고르기
보기: DC, CD, AB, BD, AD
정답: DC
풀이: 교환법칙으로 순서를 바꾸면 [DB] + [BA] + [AC] = [DC]예요.

## 상
문제: 서로 다른 네 점 A, B, C, D에 대하여 <보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. [AB] + [BC] + [CA] = $\vv{0}$\nㄴ. [AB] − [AC] = [BC]\nㄷ. [AC] + [BA] + [DB] = [DC]
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 3
풀이: ㄱ. A에서 출발해 A로 돌아오므로 영벡터 (참). ㄴ. [AB] − [AC] = [AB] + [CA] = [CB]이므로 거짓. ㄷ. 순서를 바꿔 [DB] + [BA] + [AC] = [DC] (참).

# 상자 4 · 벡터의 뺄셈
- 방: 2
- 협업: 아니오
- 그림: hex
- 개념: 벡터의 뺄셈

## 하
문제: 평행사변형 ABCD에서 두 대각선의 교점을 O라 하고 [OA] = {a}, [OB] = {b}라 할 때, 벡터 [AB]를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: -a+b
풀이: [AB] = [OB] − [OA] = {b} − {a}

## 중
문제: 정육각형 ABCDEF에서 세 대각선 AD, BE, CF의 교점을 O라 하고 [OA] = {a}, [OC] = {b}라 할 때, 벡터 [OE]를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: -a-b
풀이: O에서 한 꼭짓점씩 건너뛴 세 벡터 [OA], [OC], [OE]는 크기가 같고 120°씩 벌어져 있어서 합이 영벡터예요. 따라서 [OE] = −{a} − {b}

## 상
문제: 정육각형 ABCDEF에서 세 대각선 AD, BE, CF의 교점을 O라 하고 [OA] = {a}, [OC] = {b}라 할 때, 벡터 [AE] + [FD]를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: -3a
풀이: [OE] = −{a} − {b}, [OD] = −{a}, [OF] = −{b}예요. [AE] = [OE] − [OA] = −2{a} − {b}, [FD] = [OD] − [OF] = −{a} + {b}이므로 합은 −3{a}

# 상자 5 · 공간에서 벡터 나타내기
- 방: 2
- 협업: 아니오
- 그림: cuboid
- 개념: 벡터의 덧셈 (삼각형법·평행사변형법)

## 하
문제: 직육면체 ABCD-EFGH에서 [AB] = {a}, [AD] = {b}, [AE] = {c}라 할 때, 벡터 [AG]를 {a}, {b}, {c}로 나타내시오.
답 형식: 벡터식
정답: a+b+c
풀이: [AG] = [AB] + [BC] + [CG] = {a} + {b} + {c}

## 중
문제: 직육면체 ABCD-EFGH에서 [AB] = {a}, [AD] = {b}, [AE] = {c}라 할 때, 벡터 [DF]를 {a}, {b}, {c}로 나타내시오.
답 형식: 벡터식
정답: a-b+c
풀이: [DF] = [AF] − [AD] = ({a} + {c}) − {b}

## 상
문제: 직육면체 ABCD-EFGH에서 [AG] + [BH] + [CE] + [DF] = m[CG]를 만족시키는 실수 m의 값을 구하시오.
답 형식: 숫자
정답: 4
풀이: [AB] = {a}, [AD] = {b}, [AE] = {c}로 놓으면 [AG] = {a}+{b}+{c}, [BH] = −{a}+{b}+{c}, [CE] = −{a}−{b}+{c}, [DF] = {a}−{b}+{c}. 더하면 4{c}이고 [CG] = {c}이므로 m = 4

# 상자 6 · 벡터의 실수배
- 방: 3
- 협업: 예
- 그림: parallel
- 개념: 벡터의 실수배와 연산 법칙

## 하
문제: 두 벡터 {a}, {b}에 대하여 2({a} + 3{b}) − ({a} − {b})를 간단히 하시오.
답 형식: 벡터식
정답: a+7b
풀이: 분배법칙으로 2{a} + 6{b} − {a} + {b} = {a} + 7{b}

## 중
문제: 두 벡터 {a}, {b}에 대하여 3({x} − {a}) = {x} + 2{b}를 만족시키는 벡터 {x}를 {a}, {b}로 나타내시오.
답 형식: 벡터식
정답: 3/2a+b
풀이: 3{x} − 3{a} = {x} + 2{b}에서 2{x} = 3{a} + 2{b}, {x} = (3/2){a} + {b}

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 채팅으로 조건을 알려 주고 함께 푸세요. 두 벡터 {x}, {y}가 두 조건을 모두 만족시킬 때, 벡터 {x}를 {a}, {b}로 나타내시오.
조건 ㉠: {x} + {y} = 3{a} − {b}
조건 ㉡: {x} − {y} = {a} + 5{b}
답 형식: 벡터식
정답: 2a+2b
풀이: 두 식을 더하면 2{x} = 4{a} + 4{b}, 따라서 {x} = 2{a} + 2{b}

# 상자 7 · 벡터의 평행
- 방: 3
- 협업: 예
- 그림: parallel
- 개념: 벡터의 평행

## 하
문제: 영벡터가 아니고 서로 평행하지 않은 두 벡터 {a}, {b}에 대하여 두 벡터 2{a} + 3{b}와 4{a} + m{b}가 서로 평행할 때, 실수 m의 값을 구하시오.
답 형식: 숫자
정답: 6
풀이: 4{a} + m{b} = k(2{a} + 3{b})에서 k = 2, m = 3k = 6

## 중
문제: 영벡터가 아니고 서로 평행하지 않은 두 벡터 {a}, {b}에 대하여 {p} = 2{a} − 3{b}, {q} = −{a} + {b}, {r} = m{a} − 3{b}일 때, 두 벡터 {p} + {q}와 {q} − {r}가 서로 평행하도록 하는 실수 m의 값을 구하시오.
답 형식: 숫자
정답: 1
풀이: {p} + {q} = {a} − 2{b}, {q} − {r} = (−1 − m){a} + 4{b}. 평행하려면 (−1 − m) : 4 = 1 : (−2)이므로 m = 1

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 영벡터가 아니고 서로 평행하지 않은 두 벡터 {a}, {b}에 대하여 두 조건을 모두 만족시키는 실수 m의 값을 구하시오.
조건 ㉠: {p} = {a} + 2{b}, {q} = 3{a} − {b}
조건 ㉡: {r} = m{a} + 4{b}이고, 벡터 {p} + {q}와 {r}는 서로 평행하다.
답 형식: 숫자
정답: 16
풀이: {p} + {q} = 4{a} + {b}. {r} = k(4{a} + {b})에서 k = 4이므로 m = 16

# 상자 8 · 세 점이 한 직선 위에 있을 조건
- 방: 4
- 협업: 예
- 그림: collinear
- 개념: 세 점이 한 직선 위에 있을 조건

## 하
문제: 평면 위의 서로 다른 네 점 O, A, B, C에 대하여 [OA] = {a}, [OB] = {b}, [OC] = 2{a} + m{b}일 때, 세 점 A, B, C가 한 직선 위에 있도록 하는 실수 m의 값을 구하시오. (단, {a}와 {b}는 영벡터가 아니고 서로 평행하지 않다.)
답 형식: 숫자
정답: -1
풀이: [OC] = s{a} + t{b}에서 s + t = 1이면 세 점이 한 직선 위에 있어요. 2 + m = 1, m = −1

## 중
문제: 평면 위의 서로 다른 네 점 O, A, B, C에 대하여 [OA] = {a}, [OB] = {b}, [OC] = 2m{a} + (m − 5){b}일 때, 세 점 A, B, C가 한 직선 위에 있도록 하는 실수 m의 값을 구하시오. (단, {a}와 {b}는 영벡터가 아니고 서로 평행하지 않다.)
답 형식: 숫자
정답: 2
풀이: 계수의 합이 1이어야 하므로 2m + (m − 5) = 1, m = 2

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 평면 위의 서로 다른 네 점 O, A, B, C가 두 조건을 모두 만족시킬 때, 실수 m의 값을 구하시오. (단, {a}와 {b}는 영벡터가 아니고 서로 평행하지 않다.)
조건 ㉠: [OA] = {a} + {b}, [OB] = 3{a} − {b}
조건 ㉡: [OC] = 4{a} + m{b}이고, 세 점 A, B, C는 한 직선 위에 있다.
답 형식: 숫자
정답: -2
풀이: [AB] = 2{a} − 2{b}, [AC] = 3{a} + (m − 1){b}. [AC] = k[AB]에서 k = 3/2이므로 m − 1 = −3, m = −2

# 상자 9 · 벡터의 연산 종합
- 방: 4
- 협업: 예
- 그림: square
- 개념: 단위벡터

## 하
문제: 한 변의 길이가 2인 정사각형 ABCD에서 |[AB] + [AD]|를 구하시오.
답 형식: 숫자
정답: 2√2
풀이: 평행사변형법으로 [AB] + [AD] = [AC]이고, |[AC]|는 대각선의 길이 2√2

## 중
문제: 정사각형 ABCD에서 변 AB의 중점을 M, 변 AD의 중점을 N이라 하자. |[MN] − [MB]| = 2√5일 때, 이 정사각형의 한 변의 길이를 구하시오.
답 형식: 숫자
정답: 4
풀이: [MN] − [MB] = [MN] + [BM] = [BN]. 한 변을 s라 하면 |[BN]| = √(s² + (s/2)²) = (√5/2)s = 2√5, s = 4

## 상
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요. 두 조건을 모두 이용하여 점 Q가 나타내는 도형의 길이를 구하시오. (단, O는 원점)
조건 ㉠: 점 P는 원 (x − 2)² + (y − 2)² = 4 위를 움직인다.
조건 ㉡: 점 Q는 [OQ] = [OP] / |[OP]|를 만족시킨다.
답 형식: 숫자
정답: π/2

# 핵심 카드 · 벡터의 뜻과 크기
- 비석: 1
요약: 크기와 방향을 함께 갖는 양이 벡터예요.
- 점 A에서 점 B로 향하는 방향이 주어진 선분 AB를 벡터 [AB]라 하고, A를 시점, B를 종점이라 해요.
- 선분 AB의 길이가 벡터의 크기 |[AB]|예요.
- 길이·넓이·질량처럼 크기만 갖는 양은 스칼라라고 해요.

# 핵심 카드 · 단위벡터와 평면·공간벡터
- 비석: 2
요약: 크기가 1인 벡터를 단위벡터라고 해요.
- 벡터를 한 문자로 {a}처럼 나타내고, 크기는 |{a}|로 나타내요.
- 평면에서의 벡터를 평면벡터, 공간에서의 벡터를 공간벡터라고 해요.
- {a} ≠ $\vv{0}$이면 {a}/|{a}|는 {a}와 방향이 같은 단위벡터예요.

# 핵심 카드 · 서로 같은 벡터
- 비석: 3
요약: 크기와 방향이 각각 같으면 시점이 달라도 같은 벡터예요.
- 벡터를 평행이동해서 포개지면 두 벡터는 서로 같아요: {a} = {b}
- {a}와 크기는 같고 방향이 반대인 벡터를 −{a}로 나타내요.
- [BA] = −[AB]

# 핵심 카드 · 벡터의 덧셈 (삼각형법·평행사변형법)
- 비석: 4
요약: [AB] + [BC] = [AC] — 앞 벡터의 종점에 다음 벡터의 시점을 이어 붙여요.
- 삼각형법: {a}의 종점과 {b}의 시점을 일치시키면 {a}의 시점에서 {b}의 종점까지가 {a} + {b}
- 평행사변형법: 두 벡터의 시점을 일치시키고 평행사변형을 그리면 대각선이 합
- 가래를 두 사람이 당기면 두 힘의 합 방향으로 움직여요.

# 핵심 카드 · 벡터의 덧셈에 대한 연산 법칙
- 비석: 5
요약: 벡터의 덧셈은 교환법칙과 결합법칙이 성립해요.
- 교환법칙: {a} + {b} = {b} + {a}
- 결합법칙: ({a} + {b}) + {c} = {a} + ({b} + {c})이므로 괄호 없이 {a} + {b} + {c}로 써요.
- 순서를 바꿔 '꼬리에 머리'가 이어지게 정리하면 계산이 쉬워요.

# 핵심 카드 · 영벡터
- 비석: 6
요약: 시점과 종점이 같은 벡터를 영벡터 $\vv{0}$이라고 해요.
- 영벡터의 크기는 0이고 방향은 생각하지 않아요.
- {a} + $\vv{0}$ = {a}, {a} + (−{a}) = $\vv{0}$

# 핵심 카드 · 벡터의 뺄셈
- 비석: 7
요약: {a} − {b} = {a} + (−{b}) — 빼기는 방향을 뒤집어 더하기예요.
- [AB] − [AD] = [DB] (시점이 같은 두 벡터의 차는 '빼는 벡터의 종점 → 빼지는 벡터의 종점')
- [OB] − [OA] = [AB]
- 비 오는 날 우산을 기울이는 방향이 바로 (비의 속도) − (내 속도)예요.

# 핵심 카드 · 벡터의 실수배
- 비석: 8
요약: 실수 k와 벡터 {a}의 곱 k{a}는 크기가 |k||{a}|인 벡터예요.
- k > 0이면 {a}와 같은 방향, k < 0이면 반대 방향
- k = 0이거나 {a} = $\vv{0}$이면 k{a} = $\vv{0}$
- 개썰매를 끄는 개가 많을수록 같은 방향의 힘이 배로 커져요.

# 핵심 카드 · 벡터의 실수배에 대한 연산 법칙
- 비석: 9
요약: 실수배는 결합법칙과 분배법칙이 성립해요.
- 결합법칙: k(l{a}) = (kl){a}
- 분배법칙: (k + l){a} = k{a} + l{a}, k({a} + {b}) = k{a} + k{b}
- 그래서 벡터식도 문자식처럼 동류항끼리 정리할 수 있어요.

# 핵심 카드 · 벡터의 평행
- 비석: 10
요약: {a} ∥ {b} ⟺ {b} = k{a} (k ≠ 0인 실수)
- 영벡터가 아닌 두 벡터의 방향이 같거나 반대이면 서로 평행해요.
- {a}, {b}가 서로 평행하지 않을 때 s{a} + t{b} = s'{a} + t'{b}이면 s = s', t = t'
- 이 성질로 계수를 비교해 미지수를 구해요.

# 핵심 카드 · 세 점이 한 직선 위에 있을 조건
- 비석: 11
요약: [AC] = k[AB]인 0이 아닌 실수 k가 있으면 세 점 A, B, C는 한 직선 위에 있어요.
- 역으로 세 점이 한 직선 위에 있으면 이런 k가 있어요.
- [OC] = s[OA] + t[OB]일 때 (O, A, B가 한 직선 위에 있지 않으면) 세 점 A, B, C가 한 직선 위 ⟺ s + t = 1
