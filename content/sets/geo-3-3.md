# 상자 1 · 좌표평면에서 직선의 방정식
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 좌표평면에서 직선의 방정식

## 하
그림: 평면 A=1,2 u=3,-1@A P=A+t*u 슬라이더=t,-3,3,1 직선=A,u 보기=P
조작: t를 움직여 직선 위의 점 P가 x축(y = 0) 위에 오는 순간을 찾아보세요.
문제: 점 (1, 2)를 지나고 방향벡터가 {u} = (3, −1)인 직선이 x축과 만나는 점의 x좌표를 구하시오.
답 형식: 숫자
정답: 7
풀이: 직선의 방정식은 (x − 1)/3 = (y − 2)/(−1)이에요. y = 0을 넣으면 (x − 1)/3 = 2, x = 7

## 중
그림: 평면 A=1,3 B=3,7 P=A+t*AB 슬라이더=t,-1,3,0.5 직선=A,AB 보기=P
조작: t를 움직여 직선 위의 점 P의 y좌표가 11이 되는 순간을 찾아보세요.
문제: 두 점 A(1, 3), B(3, 7)을 지나는 직선이 점 (k, 11)을 지날 때,\nk의 값을 구하시오.
답 형식: 숫자
정답: 5
풀이: 방향벡터 [AB] = (2, 4)이므로 (x − 1)/2 = (y − 3)/4. y = 11을 넣으면 (x − 1)/2 = 2, x = 5

## 상
그림: 평면 O=0,0 A=1,-1 u=2,3@A v=3,-2 직선=A,u;O,v 보기=ㄱ:u;ㄴ:(3,3)-A;ㄷ:u·v
조작: ㄴ: (3, 3)−A가 방향벡터의 실수배인지, ㄷ: 두 방향벡터의 내적이 0인지 확인해 보세요.
문제: 직선 l: (x − 1)/2 = (y + 1)/3에 대하여\n<보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. 직선 l의 방향벡터는 (2, 3)이다.\nㄴ. 직선 l은 점 (3, 3)을 지난다.\nㄷ. 직선 l은 직선 x/3 = y/(−2)와 수직이다.
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 3
풀이: ㄱ. 분모가 방향벡터의 성분이므로 참. ㄴ. (3 − 1)/2 = 1, (3 + 1)/3 = 4/3이 같지 않으므로 거짓. ㄷ. (2, 3)·(3, −2) = 0이므로 참.

# 상자 2 · 좌표공간에서 직선의 방정식
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 좌표공간에서 직선의 방정식

## 하
그림: 공간 A=1,-2,3 u=2,1,-1@A P=A+t*u 슬라이더=t,-2,3,1 직선=A,u 보기=P
조작: t를 움직여 x좌표가 5인 점을 찾아보세요. 그림은 끌어서 돌릴 수 있어요.
문제: 점 (1, −2, 3)을 지나고 방향벡터가 {u} = (2, 1, −1)인 직선 위의 점 중에서\nx좌표가 5인 점의 z좌표를 구하시오.
답 형식: 숫자
정답: 1
풀이: 직선 위의 점은 (1 + 2t, −2 + t, 3 − t). x = 5이면 t = 2이므로 z = 3 − 2 = 1

## 중
그림: 공간 A=1,0,2 B=3,2,-2 P=A+t*AB 슬라이더=t,-2,2,0.5 직선=A,AB 보기=P
조작: t를 움직여 z좌표가 6인 점을 찾아보세요.
문제: 두 점 A(1, 0, 2), B(3, 2, −2)를 지나는 직선이 점 (a, b, 6)을 지날 때,\na + b의 값을 구하시오.
답 형식: 숫자
정답: -3
풀이: 방향벡터 [AB] = (2, 2, −4), 직선 위의 점 (1 + 2t, 2t, 2 − 4t). z = 6이면 t = −1이므로 a = −1, b = −2

## 상
그림: 공간 C=2,-1,1 v=3,-1,2@C P=C+t*v 슬라이더=t,-3,2,1 직선=C,v 보기=P
조작: 평행한 직선은 방향벡터가 같아요. t를 움직여 y좌표가 1인 점을 찾아보세요.
문제: 점 (2, −1, 1)을 지나고 직선 (x − 1)/3 = (y + 2)/(−1) = z/2에 평행한 직선이 점 (a, 1, b)를 지날 때,\na + b의 값을 구하시오.
답 형식: 숫자
정답: -7
풀이: 평행한 직선은 방향벡터가 같아요: (3, −1, 2). 직선 위의 점 (2 + 3t, −1 − t, 1 + 2t)에서 y = 1이면 t = −2, a = −4, b = −3

# 상자 3 · 두 직선이 이루는 각
- 방: 1
- 협업: 아니오
- 그림: 없음
- 개념: 두 직선이 이루는 각

## 하
그림: 평면 u=1,0 v=1,1 끌기=u,v 보기=cosθ:|u·v|/(|u|*|v|)
조작: cos θ 값을 보고 두 직선이 이루는 각을 생각해 보세요. 방향벡터를 끌어 바꿔 볼 수도 있어요.
문제: 방향벡터가 각각 (1, 0), (1, 1)인 두 직선이 이루는 각의 크기 θ를 구하시오. (도 단위의 수로 답하시오. 예: 30)
답 형식: 숫자
정답: 45
풀이: cos θ = |(1, 0)·(1, 1)| / (1 × √2) = √2/2이므로 θ = 45°

## 중
그림: 공간 u=1,1,0 v=1,0,1 화살표=u,v 보기=cosθ:|u·v|/(|u|*|v|)
조작: 두 직선의 방향벡터를 돌려 보고, cos θ 값으로 각을 구해 보세요.
문제: 두 직선 x − 1 = y + 2, z = 3과 x = z − 1, y = 2가 이루는 각의 크기 θ를 구하시오. (도 단위의 수로 답하시오.)
답 형식: 숫자
정답: 60
풀이: 방향벡터는 (1, 1, 0)과 (1, 0, 1). cos θ = 1 / (√2 × √2) = 1/2이므로 θ = 60°

## 상
그림: 공간 u=1,1,k v=1,0,1 슬라이더=k,-6,2,1 화살표=u,v 보기=두_직선의_각:각선(u,v)
조작: k를 움직여 두 직선이 이루는 각이 60°가 되는 값을 모두 찾아보세요 (k ≠ 0).
문제: 두 직선 x − 1 = y + 2 = z/k와 x = z − 1, y = 2가 이루는 각의 크기가 60°일 때,\n실수 k의 값을 구하시오.\n(단, k ≠ 0)
답 형식: 숫자
정답: -4
풀이: 방향벡터 (1, 1, k)와 (1, 0, 1). cos 60° = |1 + k| / (√(2 + k²) × √2) = 1/2에서 2(1 + k)² = 2 + k², k² + 4k = 0. k ≠ 0이므로 k = −4

# 상자 4 · 직선의 평행과 수직
- 방: 2
- 협업: 아니오
- 그림: 없음
- 개념: 두 직선의 평행과 수직

## 하
그림: 평면 u=2,k v=4,6 슬라이더=k,-2,6,1 화살표=u,v 보기=두_직선의_각:각선(u,v)
조작: k를 움직여 두 직선이 평행(각 0°)해지는 순간을 찾아보세요.
문제: 두 직선 (x − 1)/2 = (y + 3)/k와 x/4 = (y − 1)/6이 서로 평행할 때,\n실수 k의 값을 구하시오.
답 형식: 숫자
정답: 3
풀이: 방향벡터 (2, k)와 (4, 6)이 평행해야 하므로 k = 3

## 중
그림: 공간 u=2,-1,3 v=1,k,2 슬라이더=k,0,10,1 화살표=u,v 보기=u·v
조작: k를 움직여 두 방향벡터의 내적이 0이 되는 순간을 찾아보세요.
문제: 두 직선 (x − 1)/2 = (y + 1)/(−1) = z/3과 x = (y − 2)/k = (z + 1)/2가 서로 수직일 때,\n실수 k의 값을 구하시오.
답 형식: 숫자
정답: 8
풀이: 방향벡터 (2, −1, 3)·(1, k, 2) = 2 − k + 6 = 0이므로 k = 8

## 상
그림: 공간 u1=2,-1,2 u2=-4,2,-4 u3=1,4,1 P=0,3,1 Q=-4,5,3 화살표=u1,u2,u3 보기=ㄱ:각선(u1,u2);ㄴ:u1·u3;ㄷ:Q-P
조작: ㄱ은 각이 0°인지, ㄴ은 내적이 0인지, ㄷ은 Q−P가 {u2}의 실수배인지 확인해 보세요.
문제: 세 직선 l₁: (x − 1)/2 = y/(−1) = (z + 1)/2, l₂: x/(−4) = (y − 3)/2 = (z − 1)/(−4), l₃: x = (y − 1)/4 = z + 2에 대하여\n<보기>에서 옳은 것만을 있는 대로 고른 것은?\n\n[보기]\nㄱ. l₁ ∥ l₂\nㄴ. l₁ ⊥ l₃\nㄷ. l₂는 점 (−4, 5, 3)을 지난다.
답 형식: 오지선다
보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ
정답: 2
풀이: ㄱ. (−4, 2, −4) = −2(2, −1, 2)이므로 참. ㄴ. (2, −1, 2)·(1, 4, 1) = 0이므로 참. ㄷ. −4/(−4) = 1, (5 − 3)/2 = 1, (3 − 1)/(−4) = −1/2로 같지 않으므로 거짓.

# 상자 5 · 평면의 방정식
- 방: 2
- 협업: 아니오
- 그림: 없음
- 개념: 평면의 방정식

## 하
그림: 공간 n=2,1,3@A A=1,-1,2 X=s,0,0 슬라이더=s,0,5,0.5 평면=n,-7 화살표=n 보기=AX·n
조작: 점 X를 x축 위에서 움직여 [AX]가 법선벡터와 수직(내적 0)이 되는 순간을 찾아보세요.
문제: 점 (1, −1, 2)를 지나고 법선벡터가 {n} = (2, 1, 3)인 평면이 x축과 만나는 점의 x좌표를 구하시오.
답 형식: 숫자
정답: 7/2
풀이: 2(x − 1) + (y + 1) + 3(z − 2) = 0, 즉 2x + y + 3z − 7 = 0. y = z = 0이면 x = 7/2

## 중
그림: 공간 n=1,-2,2@A A=2,0,-1 Q=a,1,1 슬라이더=a,-3,3,0.5 평면=n,0 화살표=n 보기=AQ·n
조작: a를 움직여 [AQ]·{n} = 0, 즉 Q가 평면 위에 오는 값을 찾아보세요.
문제: 점 (2, 0, −1)을 지나고 직선 x − 1 = (y + 2)/(−2) = z/2에 수직인 평면이 점 (a, 1, 1)을 지날 때,\na의 값을 구하시오.
답 형식: 숫자
정답: 0
풀이: 직선의 방향벡터 (1, −2, 2)가 평면의 법선벡터예요. (x − 2) − 2y + 2(z + 1) = 0, 즉 x − 2y + 2z = 0. a − 2 + 2 = 0이므로 a = 0

## 상
그림: 공간 A=1,1,1 n=2,-1,2@A H=A+k*n 슬라이더=k,-1,1/3,1/3 평면=n,3 화살표=n 보기=H;평면에_넣은_값:n·H+3
조작: k를 움직여 H가 평면 위에 오는(넣은 값이 0) 순간을 찾아보세요.
문제: 점 A(1, 1, 1)에서\n평면 2x − y + 2z + 3 = 0에 내린 수선의 발을 H(a, b, c)라 할 때,\na + b + c의 값을 구하시오.
답 형식: 숫자
정답: 1
풀이: [AH] = k(2, −1, 2)이므로 H(1 + 2k, 1 − k, 1 + 2k). 평면에 넣으면 9k + 6 = 0, k = −2/3. H(−1/3, 5/3, −1/3)이므로 합은 1

# 상자 6 · 두 평면의 위치 관계
- 방: 3
- 협업: 예
- 그림: 없음
- 개념: 두 평면이 이루는 각

## 하
그림: 공간 n1=1,2,-1 n2=2,k,-2 슬라이더=k,0,8,1 평면=n1,-3;n2,-1 화살표=n1,n2 보기=두_평면의_각:각선(n1,n2)
조작: k를 움직여 두 평면이 평행해지는(법선벡터의 각 0°) 순간을 찾아보세요.
문제: 두 평면 x + 2y − z = 3과 2x + ky − 2z = 1이 서로 평행할 때,\n실수 k의 값을 구하시오.
답 형식: 숫자
정답: 4
풀이: 법선벡터 (1, 2, −1)과 (2, k, −2)가 평행해야 하므로 k = 4

## 중
그림: 공간 n1=1,1,0 n2=0,1,1 평면=n1,-1;n2,-2 화살표=n1,n2 보기=cosθ:|n1·n2|/(|n1|*|n2|)
조작: 두 법선벡터로 cos θ를 보고 두 평면이 이루는 각을 구해 보세요.
문제: 두 평면 x + y = 1과 y + z = 2가 이루는 각의 크기 θ를 구하시오. (도 단위의 수로 답하시오.)
답 형식: 숫자
정답: 60
풀이: 법선벡터 (1, 1, 0)과 (0, 1, 1). cos θ = 1 / (√2 × √2) = 1/2이므로 θ = 60°

## 상
그림: 공간 n1=1,k,1 n2=k,k,-3 슬라이더=k,-3,2,0.1 평면=n1,1;n2,0 화살표=n1,n2 보기=n1·n2
조작: k를 움직여 법선벡터의 내적이 0에 가까워지는 곳을 두 군데 찾아보세요. 두 값의 합은?
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요.\n채팅으로 조건을 알려 주고 함께 푸세요.\n두 평면 α, β가 서로 수직이 되도록 하는 모든 실수 k의 값의 합을 구하시오.
조건 ㉠: 평면 α: x + ky + z + 1 = 0
조건 ㉡: 평면 β: kx + ky − 3z = 0
답 형식: 숫자
정답: -1
풀이: 법선벡터의 내적 (1, k, 1)·(k, k, −3) = k² + k − 3 = 0. 판별식이 양수이므로 서로 다른 두 실근이 있고, 근과 계수의 관계에서 합은 −1

# 상자 7 · 점과 평면 사이의 거리
- 방: 3
- 협업: 예
- 그림: 없음
- 개념: 점과 평면 사이의 거리

## 하
그림: 공간 n=2,-1,2 H=k*n 슬라이더=k,0,2,0.25 평면=n,-9 화살표=H 보기=평면에_넣은_값:n·H-9;|H|
조작: k를 움직여 수선의 발 H가 평면 위에 오는 순간을 찾아보세요.
문제: 원점과 평면 2x − y + 2z = 9 사이의 거리를 구하시오.
답 형식: 숫자
정답: 3
풀이: 원점에서 내린 수선의 발은 k(2, −1, 2) 꼴이에요. 9k = 9에서 k = 1, 거리는 |(2, −1, 2)| = 3

## 중
그림: 공간 A=1,-1,2 n=1,2,2 H=A+k*n 슬라이더=k,0,1,1/9 평면=n,-7 화살표=AH 보기=평면에_넣은_값:n·H-7;|AH|
조작: k를 움직여 H가 평면 위에 오는 순간을 찾고, 그때 |[AH]|를 보세요.
문제: 점 (1, −1, 2)와 평면 x + 2y + 2z − 7 = 0 사이의 거리를 구하시오.
답 형식: 숫자
정답: 4/3
풀이: 수선의 발을 (1 + k, −1 + 2k, 2 + 2k)로 놓고 평면에 넣으면 9k − 4 = 0, k = 4/9. 거리는 |k| × |(1, 2, 2)| = 4/9 × 3 = 4/3

## 상
그림: 공간 P=1,2,3 n=1,1,1 H=P+k*n Q=2H-P 슬라이더=k,-2,0,0.5 평면=n,-3 화살표=PH 보기=평면에_넣은_값:n·H-3;Q
조작: k를 움직여 H가 평면 위에 오게 한 뒤, 대칭점 Q의 좌표로 |[OQ]|를 구해 보세요.
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요.\n점 P를 평면 α에 대하여\n대칭이동한 점을 Q라 할 때,\n|[OQ]|의 값을 구하시오.\n(단, O는 원점)
조건 ㉠: 점 P(1, 2, 3)
조건 ㉡: 평면 α: x + y + z = 3
답 형식: 숫자
정답: √2
풀이: P에서 내린 수선의 발 H = P + k(1, 1, 1)에서 6 + 3k = 3, k = −1, H(0, 1, 2). Q = 2H − P = (−1, 0, 1)이므로 |[OQ]| = √2

# 상자 9 · 벡터방정식과 도형
- 방: 4
- 협업: 예
- 그림: 없음
- 개념: 지름의 양 끝 점이 주어진 구

## 하
그림: 공간 O=0,0,0 P=2cos(s),2sin(s),0 슬라이더=s,0,360,30 구=O,2 보기=|P|
조작: 점 P를 움직여 |{p}| = 2인 점들이 어떤 도형을 이루는지 보세요.
문제: 원점 O와 점 P의 위치벡터를 {p}라 할 때,\n|{p}| = 2를 만족시키는 점 P가 나타내는 도형의 겉넓이를 구하시오.
답 형식: 숫자
정답: 16π
풀이: 중심이 원점이고 반지름이 2인 구이므로 겉넓이는 4π × 2² = 16π

## 중
그림: 공간 A=1,2,-1 B=3,-2,3 M=mid(A,B) P=M+(|AB|/2)*(cos(s),sin(s),0) 슬라이더=s,0,360,30 구=M,|AB|/2 선분=AB 화살표=AP,BP 보기=AP·BP;|AB|
조작: P를 움직여도 [AP]·[BP] = 0이에요. 지름이 AB인 구의 반지름을 구해 보세요.
문제: 두 점 A(1, 2, −1), B(3, −2, 3)과 점 P의 위치벡터를 각각 {a}, {b}, {p}라 할 때,\n({p} − {a})·({p} − {b}) = 0을 만족시키는 점 P가 나타내는 도형의 부피를 구하시오.
답 형식: 숫자
정답: 36π
풀이: [AP]·[BP] = 0이므로 ∠APB = 90°, P는 선분 AB를 지름으로 하는 구 위에 있어요. 반지름 |[AB]|/2 = 6/2 = 3, 부피는 (4/3)π × 27 = 36π

## 상
그림: 공간 A=2,2,1 c=A/2 구=c,|A|/2 화살표=A 보기=중심:c;|A|
조작: 식을 정리하면 중심이 {a}/2인 구가 돼요. 그림을 돌려 확인하고 반지름으로 부피를 구해 보세요.
문제: 🤝 두 사람이 조건을 하나씩 나눠 가졌어요.\n두 조건을 만족시키는 점 P가 나타내는 도형의 부피를 구하시오.\n(단, O는 원점)
조건 ㉠: 점 A(2, 2, 1)
조건 ㉡: [OA]·[OP] = |[OP]|²
답 형식: 숫자
정답: 9π/2
풀이: {p}·{p} − {a}·{p} = 0은 |{p} − {a}/2|² = |{a}|²/4로 바뀌어요. 중심 {a}/2, 반지름 |{a}|/2 = 3/2인 구이므로 부피는 (4/3)π × 27/8 = 9π/2

# 핵심 카드 · 직선의 벡터방정식
- 비석: 1
요약: 점 A를 지나고 벡터 {u}에 평행한 직선: {p} = {a} + t{u} (t는 실수)
- {u}를 직선의 방향벡터라고 해요.
- 점 P가 직선 위에 있으면 [AP] = t{u}인 실수 t가 있어요.
- 비행기구름처럼 한 방향으로 곧게 가는 자취가 직선이에요.

# 핵심 카드 · 좌표평면에서 직선의 방정식
- 비석: 2
요약: 점 (x₁, y₁)을 지나고 방향벡터가 (u₁, u₂)인 직선: (x − x₁)/u₁ = (y − y₁)/u₂
- (단, u₁u₂ ≠ 0) u₁ = 0이면 x = x₁, u₂ = 0이면 y = y₁
- 두 점 A, B를 지나는 직선은 방향벡터로 [AB]를 써요.

# 핵심 카드 · 좌표공간에서 직선의 방정식
- 비석: 3
요약: 점 (x₁, y₁, z₁)을 지나고 방향벡터가 (u₁, u₂, u₃)인 직선: (x − x₁)/u₁ = (y − y₁)/u₂ = (z − z₁)/u₃
- 매개변수로 쓰면 x = x₁ + tu₁, y = y₁ + tu₂, z = z₁ + tu₃
- 성분 하나가 0이면 그 좌표는 일정해요. 예: u₃ = 0이면 z = z₁

# 핵심 카드 · 두 직선이 이루는 각
- 비석: 4
요약: 방향벡터가 {u}, {v}인 두 직선이 이루는 각 θ (0° ≤ θ ≤ 90°): cos θ = |{u}·{v}| / (|{u}||{v}|)
- 두 벡터가 이루는 각이 둔각이면 그 보각이 두 직선이 이루는 각이에요. 그래서 절댓값을 써요.

# 핵심 카드 · 두 직선의 평행과 수직
- 비석: 5
요약: 두 직선의 평행·수직은 방향벡터의 평행·수직으로 판단해요.
- l₁ ∥ l₂ ⟺ {u} ∥ {v} (방향벡터의 성분의 비가 같다)
- l₁ ⊥ l₂ ⟺ {u}·{v} = 0

# 핵심 카드 · 평면의 벡터방정식
- 비석: 6
요약: 점 A를 지나고 벡터 {n}에 수직인 평면: ({p} − {a})·{n} = 0
- {n}을 평면의 법선벡터라고 해요.
- 평면에 수직인 직선의 방향벡터는 그 평면의 법선벡터예요.

# 핵심 카드 · 평면의 방정식
- 비석: 7
요약: 점 (x₁, y₁, z₁)을 지나고 법선벡터가 (a, b, c)인 평면: a(x − x₁) + b(y − y₁) + c(z − z₁) = 0
- 일차방정식 ax + by + cz + d = 0은 법선벡터가 (a, b, c)인 평면이에요.
- 평면이 축과 만나는 점은 나머지 두 좌표를 0으로 놓아 구해요.

# 핵심 카드 · 두 평면이 이루는 각
- 비석: 8
요약: 법선벡터가 {n₁}, {n₂}인 두 평면이 이루는 각 θ (0° ≤ θ ≤ 90°): cos θ = |{n₁}·{n₂}| / (|{n₁}||{n₂}|)
- α ∥ β ⟺ {n₁} ∥ {n₂}
- α ⊥ β ⟺ {n₁}·{n₂} = 0

# 핵심 카드 · 점과 평면 사이의 거리
- 비석: 9
요약: 점 A에서 평면에 내린 수선의 발 H에 대하여 거리는 |[AH]|예요.
- [AH]는 법선벡터에 평행하므로 [AH] = k{n}으로 놓아요.
- H가 평면 위에 있다는 조건으로 k를 구하면 거리 = |k||{n}|
- 점을 평면에 대해 대칭이동한 점은 Q = 2H − A

# 핵심 카드 · 구의 벡터방정식
- 비석: 10
요약: 중심 A, 반지름 r인 구: |{p} − {a}| = r 또는 ({p} − {a})·({p} − {a}) = r²
- 성분으로 쓰면 (x − x₁)² + (y − y₁)² + (z − z₁)² = r²
- 게임과 3D 애니메이션도 평면과 구의 벡터방정식으로 사물을 표현해요.

# 핵심 카드 · 지름의 양 끝 점이 주어진 구
- 비석: 11
요약: 두 점 A, B를 지름의 양 끝 점으로 하는 구: ({p} − {a})·({p} − {b}) = 0
- 원주각의 성질로 ∠APB = 90°, 즉 [AP] ⊥ [BP]
- 중심은 선분 AB의 중점, 반지름은 |[AB]|/2
