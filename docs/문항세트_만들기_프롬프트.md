# 문항 세트(md) 만들기: AI에게 요청하는 방법

교과서 파일만 주고 "문제 만들어 줘"라고 하면, 형식이 맞지 않아 업로드 검사에서 오류가 많이 납니다.
아래 순서대로 **형식 예시 파일 + 교과서 쪽 + 프롬프트**를 함께 주면 한 번에 올릴 수 있는 파일이 나옵니다.

## 순서

1. 교사 화면 → 📤 문항 세트 올리기 → **📄 형식 예시 받기**로 `geo-3-1.md`를 내려받습니다.
2. AI(Claude 등)에게 세 가지를 함께 줍니다.
   - 내려받은 예시 파일 `geo-3-1.md`. 가장 중요합니다. AI가 이 파일의 모양을 그대로 따라 합니다.
   - 만들 단원의 교과서 쪽(PDF나 사진)이나 성취기준
   - 아래 **프롬프트 1**
3. AI가 만든 md 파일을 교사 화면의 **🔎 검사만 하기**로 확인합니다.
4. 오류가 나오면 오류 문장을 그대로 복사해 **프롬프트 3**과 함께 AI에게 줍니다.
5. 검사를 통과하면 **📤 검사 후 저장**을 누릅니다. 중간관리자가 올리면 그 채널에만 보이고, 그 채널에만 적용됩니다.

## 프롬프트 1: 세트 전체 만들기 (복사해서 쓰세요)

```
첨부한 geo-3-1.md는 수학 방탈출 게임의 문항 세트 파일 예시입니다.
첨부한 교과서 [과목명] [단원명] ([쪽수]쪽)을 바탕으로, 예시 파일과 똑같은 형식의 새 md 파일을 만들어 주세요.

[전체 구성]
- 맨 위 머리말(--- 사이):
  - 세트: 영문 소문자·숫자·하이픈 이름 (예: math1-2-3). geo-3-1처럼 기본 세트 이름은 쓰지 마세요.
  - 제목, 교과, 단원, 출처
- 상자 9개(# 상자 1 ~ # 상자 9). 상자마다 ## 하, ## 중, ## 상 세 문항 → 모두 27문항
- 방 배치는 꼭 이대로: 상자 1~3은 방 1, 상자 4~5는 방 2, 상자 6~7은 방 3, 상자 8~9는 방 4
- 협업: 상자 6~9는 "협업: 예", 나머지는 "협업: 아니오"
  - 협업 상자의 ## 상 문항에는 "조건 ㉠:", "조건 ㉡:" 두 줄을 넣어 주세요.
  - 두 조건을 모두 알아야만 풀리게 만들어 주세요.
  - 문제 첫 줄은 "🤝 두 사람이 조건을 하나씩 나눠 가졌어요.\n채팅으로 조건을 알려 주고 함께 푸세요.\n"로 시작합니다.
- 상자 순서는 교과서의 개념 순서를 따르고, 상자 이름은 그 상자에서 다루는 개념으로 정해 주세요.
- 난이도
  - 하: 교과서 예제 수준 (개념을 바로 적용)
  - 중: 교과서 문제·중단원 마무리 수준
  - 상: 수능·심화 수준 (개념 2개 이상 연결)
- 숫자는 교과서와 다르게 새로 정해 주세요(저작권). 문제 유형과 개념 순서만 따릅니다.

[문항 한 개의 줄 순서]
그림: / 조작: / 문제: / 답 형식: / (보기:) / 정답: / 풀이:

[문제 문장 규칙]
- 한 줄로 길게 쓰지 말고 \n으로 줄을 나눠 주세요.
  (조건 → 정의 → 묻는 것 순서. 예: "정육각형 ABCDEF에서\n세 대각선의 교점을 O라 하자.\n…를 구하시오.")
- 벡터 표기
  - 벡터 AB는 [AB], 벡터 a는 {a}, 영벡터는 $\vv{0}$
  - 크기는 |[AB]|, |{a}|
- 수식 기호는 √, π, θ, °, ², ·, ⊥, ∥, ≠, ≤를 그대로 써도 됩니다(자동으로 MathJax가 됩니다).
  복잡한 식은 $...$ 안에 TeX로 쓰세요.
- 합답형(ㄱ, ㄴ, ㄷ)은 이렇게 씁니다.
  - 문제 끝에 "\n\n[보기]\nㄱ. …\nㄴ. …\nㄷ. …"를 붙입니다.
  - "답 형식: 오지선다"와 "보기: ① ㄱ | ② ㄱ, ㄴ | ③ ㄱ, ㄷ | ④ ㄴ, ㄷ | ⑤ ㄱ, ㄴ, ㄷ"을 씁니다.
  - 정답은 번호(1~5)로 씁니다.

[답 형식]
- 숫자: 정답은 2√5, 1/2, π/2, -3처럼 하나의 값
- 오지선다: 보기 5개를 | 로 구분, 정답은 번호
- 고르기: 보기를 쉼표로 나열, 정답도 쉼표로 (예: FO, OC)
- 벡터식: 정답은 -a+2b, 1/3a+2/3b처럼 문자 벡터의 일차결합
- 답이 방정식이면, 방정식에서 나오는 값(좌표, 각의 크기, 거리, 넓이)을 묻는 숫자 문제로 바꿔 주세요.

[그림(그림:)과 조작(조작:) — 모든 문항에 넣어 주세요]
학생이 그림을 직접 끌고 움직이며 답을 찾아가게 하는 것이 목적입니다. 예시 파일의 그림 줄과 같은 문법을 쓰세요.
- 그림: 평면(또는 공간) 다음에 이름=값을 띄어서 씁니다.
  - 소문자는 벡터나 조절기 (a=2,1), 대문자는 점 (A=0,0), AB는 B−A
  - 끌기=A,b (끌 수 있는 점·벡터)
  - 슬라이더=t,0,1,0.1 (이름, 최소, 최대, 간격. 여러 개는 ; 로)
  - 화살표=a,b,AB / 선분=AB / 다각형=ABCD
  - 직선=P,u / 원 / 평면=n,d / 구=C,r / 직육면체=가로,세로,높이
  - 보기=이름표:식;식 (그림 아래에 값이 실시간으로 나옵니다. 이름표는 12자 이내, 띄어쓰기는 _)
  - 함수: |v| 크기, 각(u,v) 각도, mid(A,B) 중점, cen(A,B,C) 무게중심, cos·sin(도 단위)
- 합답형은 보기=에 ㄱ, ㄴ, ㄷ 각각의 양쪽 값을 띄워, 학생이 조작하며 참·거짓을 확인하게 해 주세요.
  (예: 보기=ㄱ왼쪽:AB+AF;ㄱ오른쪽:AO)
- 조작: 그림을 어떻게 움직이면 답의 실마리가 보이는지 한 문장으로 안내합니다.
  답을 직접 알려 주지는 마세요. (예: "t를 움직여 AP : PB = 2 : 1이 되는 순간을 찾아보세요.")

[풀이]
- 학생이 두 번 틀리면 힌트로 보이는 문장입니다.
- 계산 과정을 2~3단계로 쓰고, 마지막에 답을 밝혀 주세요.

[핵심 카드 — 10장 안팎]
상자 9개를 다 쓴 뒤 파일 끝에 이 모양으로 씁니다.
# 핵심 카드 · (개념 이름)
- 비석: (이 카드를 보여 줄 상자 번호 1~9)
요약: (한 문장 정의나 공식)
- (설명이나 성질 2~4줄)
- 각 상자 머리의 "- 개념:" 이름과 카드 제목을 똑같이 맞춰 주세요.

[마지막 확인]
- 27문항의 정답을 직접 다시 계산해 검산해 주세요.
- 오지선다는 보기가 꼭 5개인지 확인해 주세요.
- 결과는 설명 없이 md 파일 하나로 주세요.
```

## 프롬프트 2: 그림만 보강하기

이미 문항은 있는데 그림이 약할 때 씁니다.

```
첨부한 md 파일의 모든 문항(## 하/중/상)에 대해 "그림:"과 "조작:" 줄을 다시 써 주세요.
- 학생이 점을 끌거나 조절기를 움직여 답을 스스로 발견하도록 설계해 주세요.
- 문제의 수치와 그림의 수치가 맞아야 합니다.
- 합답형은 ㄱ, ㄴ, ㄷ 양쪽 값을 보기=에 띄워 주세요.
- 문법은 예시 파일 geo-3-1.md의 그림 줄과 같게 하고, 그 밖의 줄은 바꾸지 마세요.
```

## 프롬프트 3: 검사 오류 고치기

```
수학 게임 업로드 검사에서 아래 오류가 나왔습니다. 첨부한 md 파일에서 해당 부분만 고쳐 전체 파일을 다시 주세요.
(여기에 교사 화면의 오류 문장을 그대로 붙여 넣기)
```

## 좋은 결과를 얻는 요령

- **예시 파일을 꼭 함께 주세요.** 형식을 말로 설명하는 것보다 예시 하나를 보여 주는 쪽이 훨씬 정확합니다.
- **교과서는 필요한 쪽만** 주세요. 단원 전체보다 그 소단원의 개념과 예제·문제 쪽이 좋습니다.
- **한 번에 9상자가 길면** "상자 1~3만 먼저" → "이어서 4~6" → "7~9와 핵심 카드"로 나눠 요청해도 됩니다. 마지막에 하나의 파일로 합쳐 달라고 하세요.
- **검사 통과 후에도** 연습 삼아 그 채널에 적용하고 학생 화면에서 상자 2~3개를 직접 열어, 그림이 문제와 맞는지 확인하세요.
