# 벡터 유적 탈출

기하 Ⅲ-1 '벡터의 연산' 협동형 형성평가 3D 방탈출 게임입니다. 한 반(최대 40명)이 같은 유적에 들어와 함께 탐험합니다.

- 학생은 3D 캐릭터로 유적의 방 4개를 돌아다닙니다. 크롬북·노트북 기준으로 WASD·방향키로 이동하고, E 또는 클릭으로 엽니다.
- **상자·항아리·나무통**을 열면 벡터 문제가 나옵니다. 맞히면 🗝️ 열쇠 조각을 얻고 상자가 열립니다.
- 문제 창의 **💡 힌트 보기**로 언제든 힌트를 열 수 있고, 두 번 틀리면 힌트가 저절로 나옵니다. 힌트를 본 기록은 교사 화면에 💡로 남습니다.
- 3번·7번은 **모션 그래픽 문제**입니다. 문장이 타자 소리와 함께 한 글자씩 찍히고 그림이 저절로 움직입니다. 그림을 만지면 멈추고 직접 조작할 수 있습니다.
- 수식은 **MathJax**로 출력합니다. 문제 그림 안의 작은 라벨만 그림과 함께 움직이도록 직접 그립니다.
- **배경 음악과 효과음**이 있습니다. 다음 방으로 갈수록 음악이 고조되고, 화면 위 🔊 버튼이나 M 키로 끕니다.
- 오른쪽 위에 **실시간 랭킹**이 보이고, 누군가 문제를 맞혀 유물 조각을 찾으면 모두에게 **발견 팝업**이 뜹니다.
- **강·절벽·용암**은 벡터 점프(손으로 벡터를 끌어 맞추는 활동)를 풀어야 다리가 놓입니다.
- 한 방의 열쇠 조각을 모두 모으면 다음 방 문이 열립니다.
- **마지막 유물 제단은 반 전체 협동**입니다. 한 문제를 반 학생의 70%가 풀면 그 유물이 깨어나고, 7개가 모두 깨어나면 반 전체 탈출 성공입니다.
- 친구들의 캐릭터가 실시간으로 보이지만 문과 문제는 각자 풉니다. 그래서 학생별 형성평가 기록이 정확히 남습니다.

| 방 | 열 것 (문제) | 건널 것 (벡터 점프) |
|---|---|---|
| 1 덧셈의 방 | 상자(1), 항아리(2), 상자(3) | 강: 삼각형법 |
| 2 평행의 방 | 나무통(4), 상자(5) | 절벽: 평행사변형법, 끊어진 다리: 실수배 |
| 3 공간의 방 | 항아리(6), 보물상자(7) | 용암: 벡터 길 찾기 2단계 |
| 4 유물 제단 | 반 전체 유물 7개 | — |

## 수업 진행

방 코드는 없습니다. 모든 학생이 같은 유적 하나에 들어옵니다.

1. 교사: `/teacher`에서 교사 비밀번호를 넣고 들어갑니다. 반이 바뀌었다면 먼저 **CSV 내려받기**로 이전 반 기록을 저장한 뒤 **새 수업 시작 (기록 지우기)**를 누릅니다.
2. 학생: 첫 화면에서 이름(예: `5번 홍길동`)만 적고 들어옵니다. 대기 중에는 돌아다닐 수만 있고 열 수는 없습니다.
3. 교사가 **▶ 탐험 시작**을 누르면 상자와 장애물이 열리고, **■ 탐험 끝**을 누르면 학생 화면에 결과가 나옵니다.
4. 교사 화면에서 다음을 실시간으로 봅니다. **CSV 내려받기**로 기록을 저장할 수 있습니다.
   - 문제별 첫 시도 정답률(50% 미만은 빨간색)과 자주 나온 오답
   - 학생별 순위·점수, 들어온 시각과 탈출 시각, 현재 위치(어느 방인지), 문제별 결과와 힌트 사용

점수는 문제를 맞히면 100점, 힌트 없이 첫 시도에 맞히면 50점 더, 벡터 점프 하나에 20점입니다. 점수가 같으면 먼저 도달한 학생이 앞섭니다(`src/room.js`의 `SCORE`).

- 학생이 새로고침하거나 연결이 끊겨도 진행 상황과 위치가 그대로 이어집니다.
- 한 유적에는 최대 40명까지 들어올 수 있습니다. 두 반이 동시에 쓰면 학생과 협동 집계가 섞이니, 반마다 **새 수업 시작**을 눌러 주세요.
- 마지막 활동 뒤 24시간 동안 아무도 들어오지 않으면 기록이 자동으로 지워집니다. 학생 개인정보는 입력한 이름만 저장합니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run vendor
npm run dev
```

교사 비밀번호는 프로젝트 폴더의 `.dev.vars` 파일에 `TEACHER_PASSWORD=...` 한 줄로 적습니다. 이 파일은 git에 올라가지 않습니다. 비밀번호를 바꾸면 `npm run dev`를 다시 실행합니다.

- 교사 화면: http://127.0.0.1:8787/teacher
- 학생 화면: http://127.0.0.1:8787

`npm run vendor`는 three.js와 MathJax에서 브라우저가 쓰는 파일만 `public/vendor`로 복사합니다. 버전을 바꾼 뒤에도 다시 실행합니다.

이 상태에서는 이 컴퓨터에서만 접속할 수 있습니다. 학생 기기에서 접속하려면 아래처럼 배포해야 합니다.

## 배포 (Cloudflare Workers)

```bash
npx wrangler login
npx wrangler secret put TEACHER_PASSWORD
npm run deploy
```

두 번째 명령을 실행하면 배포 서버에서 쓸 교사 비밀번호를 묻습니다. 비밀번호를 설정하지 않으면 교사 화면에 들어갈 수 없습니다.

배포하면 `https://vector-raiders.<계정>.workers.dev` 주소가 생깁니다. Durable Objects(SQLite 저장)를 쓰며, 한 반 규모라면 무료 플랜 한도 안에서 쓸 수 있을 것으로 예상합니다. 다만 실제 요금과 한도는 Cloudflare 요금 안내에서 확인해 주세요.

학생 한 명이 처음 불러오는 양은 약 1.5MB입니다(지형 모델과 three.js 1.2MB, 내 캐릭터 0.25MB). 친구 캐릭터가 화면에 나타나면 캐릭터 종류(12가지)마다 약 0.25MB씩 더 받습니다. 한 번 받은 모델은 다시 받지 않습니다.

## 구글 시트 연동 (선택)

학생이 들어오고 나간 시각과 문제 기록이 구글 시트에 자동으로 쌓입니다. 시트에는 두 탭이 생깁니다.

- **기록**: 시각, 이름, 종류(입장·퇴장·정답·오답·힌트·벡터 점프·탈출·진행 단계·새 수업 시작), 문제, 답, 결과, 시도 횟수
- **학생별 요약**: 순위, 이름, 점수, 맞힌 문제, 힌트, 벡터 점프, 처음 접속, 마지막 접속, 탈출 시각, 접속 중 (새 수업을 시작하면 비워지고, '기록'은 남습니다)

설정 순서:

1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `google-sheets/Code.gs` 내용을 모두 붙여 넣고, 맨 위 `SECRET`을 아무도 모르는 긴 글자로 바꾼 뒤 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포하고 권한을 허용합니다. 나온 웹 앱 주소를 복사합니다.
4. 이 컴퓨터에서 쓸 때는 `.dev.vars`에 두 줄을 더하고 `npm run dev`를 다시 실행합니다.
   ```
   SHEETS_WEBHOOK_URL=복사한 웹 앱 주소
   SHEETS_SECRET=2번에서 정한 글자
   ```
   배포한 서버에서는 `npx wrangler secret put SHEETS_WEBHOOK_URL`, `npx wrangler secret put SHEETS_SECRET`로 넣습니다.

기록은 3초마다 모아서 보내고, 보내지 못하면 잠시 뒤 다시 보냅니다. 설정하지 않으면 이 기능은 꺼져 있고 게임은 그대로 동작합니다. 웹 앱 주소는 누구나 열 수 있지만 SECRET이 맞아야만 시트에 기록됩니다. 학생 이름이 구글 시트에 저장되니, 학교에서 쓰는 계정의 시트를 쓰세요.

## 시험

```bash
npm test
node scripts/loadtest.mjs http://127.0.0.1:8787 28
```

가상 학생 시뮬레이션: 가상 학생 5명이 실력과 속도를 달리해 동시에 탐험하고, 끝나면 랭킹을 출력하고 `results/`에 CSV로 남깁니다. 브라우저로 들어가 있으면 가상 학생이 돌아다니는 모습, 랭킹, 발견 팝업을 볼 수 있습니다.

```bash
node scripts/simulate.mjs http://127.0.0.1:8787 5 3
```

마지막 숫자는 빠르기입니다(1이면 실제 학생 속도, 3이면 약 1분). `--keep`을 붙이면 기존 기록을 지우지 않습니다.

`loadtest.mjs`는 학생 봇 28명이 동시에 접속해 돌아다니며 벡터 점프와 상자 문제를 끝까지 진행합니다. 일부 문제는 일부러 한 번 틀린 뒤 정답을 냅니다. 교사 비밀번호는 `.dev.vars`에서 읽습니다. **시작할 때 '새 수업 시작'을 눌러 기록을 지우므로, 수업 중인 서버에는 쓰지 마세요.**
