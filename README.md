# 벡터 유적 탈출

기하 Ⅲ-1 '벡터의 연산' 협동형 형성평가 3D 방탈출 게임입니다. 한 반(최대 40명)이 같은 유적에 들어와 함께 탐험합니다.

- 학생은 3D 캐릭터로 유적의 방 4개를 돌아다닙니다. 크롬북·노트북 기준으로 WASD·방향키로 이동하고, E 또는 클릭으로 엽니다.
- **상자·항아리·나무통**을 열면 벡터 문제가 나옵니다. 맞히면 🗝️ 열쇠 조각을 얻고 상자가 열립니다.
- 문제 창의 **💡 힌트 보기**로 언제든 힌트를 열 수 있고, 두 번 틀리면 힌트가 저절로 나옵니다. 힌트를 본 기록은 교사 화면에 💡로 남습니다.
- **모든 문제는 모션 그래픽**으로 나옵니다. 문장이 타자 소리와 함께 한 글자씩 찍히고 그림이 저절로 움직입니다(벡터가 꼭짓점을 돌아다니기, 슬라이더가 저절로 바뀌기, 직육면체 회전 등). 그림이나 슬라이더를 만지면 멈추고 직접 조작할 수 있습니다.
- 수식은 **MathJax**로 출력합니다. 문제 그림 안의 작은 라벨만 그림과 함께 움직이도록 직접 그립니다.
- **배경 음악과 효과음**이 있습니다. 다음 방으로 갈수록 음악이 고조되고, 화면 위 🔊 버튼이나 M 키로 끕니다.
- **첫 화면**: 기하 기호가 쏟아지는 배경 위로 탐험가들이 달리는 타이틀(TOUCH TO START) 다음에, 카드 메뉴(연습 모드 · 수업 참가 · 설정)가 나옵니다. **설정**에서 배경음악, 효과음, 그래픽 품질(느린 크롬북은 '낮음')을 바꿉니다.
- 오른쪽 위에 **실시간 랭킹**이 보이고, 누군가 문제를 맞혀 유물 조각을 찾으면 모두에게 **발견 팝업**이 뜹니다.
- **강·절벽·용암**은 벡터 점프(손으로 벡터를 끌어 맞추는 활동)를 풀어야 다리가 놓입니다.
- 한 방의 열쇠 조각을 모두 모으면 다음 방 문이 열립니다.
- **마지막 유물 제단은 반 전체 협동**입니다. 한 문제를 반 학생의 70%가 풀면 그 유물이 깨어나고, 7개가 모두 깨어나면 반 전체 탈출 성공입니다.
- 친구들의 캐릭터가 실시간으로 보이지만 문과 문제는 각자 풉니다. 그래서 학생별 형성평가 기록이 정확히 남습니다.

| 방 | 열 것 (문제) | 건널 것 (벡터 점프) |
|---|---|---|
| 1 덧셈의 방 | 상자(1), 항아리(2), 상자(3) | 강: 삼각형법 |
| 2 평행의 방 | 나무통(4), 상자(5) | 절벽: 평행사변형법, 끊어진 다리: 실수배 |
| 3 공간의 방 | 항아리(6), 보물상자(7) | 용암: 벡터 길 찾기 2단계 |
| 4 유물 제단 | 반 전체 유물 7개 | — |

## 문항 세트 (md 파일)

문항과 핵심 카드는 코드가 아니라 `content/sets/*.md` 파일에 있습니다. 파일 맨 위의 설명대로 쓰면 되고, 지금은 `geo-3-1.md`(Ⅲ-1 벡터의 연산), `geo-3-2.md`(Ⅲ-2 벡터의 성분과 내적), `geo-3-3.md`(Ⅲ-3 도형의 방정식)가 들어 있습니다. 3-3은 답이 방정식인 문제가 많아 방정식에서 나오는 값(지나는 점의 좌표, 각, 거리, 넓이·부피)으로 답하게 했습니다.

- **세트 올리기 (다른 교과·단원으로 바꾸기)**: 전체 관리자로 교사 화면에 들어가면 🛡️ 중간관리자 관리 창 아래에 "📤 문항 세트(md) 올리기"가 있습니다. "형식 예시 받기"로 3-1 세트 파일을 받아 고쳐 쓰고, "검사만 하기"로 확인한 뒤 "검사 후 저장"을 누르면 모든 채널의 "이 채널 단원" 목록에 나타납니다. 검사는 형식(상자 9개, 하·중·상, 협업 상자의 조건 ㉠·㉡, 오지선다 보기 5개)과 함께 정답을 채점기로 직접 채점해 보아 읽을 수 없는 정답을 상자·난이도별로 알려 줍니다. 맨 위 '세트:' 이름이 같으면 덮어쓰고, 기본 세트 이름(geo-3-1 등)은 쓸 수 없습니다. 올린 세트는 Durable Object `admin:global`에 저장되고 지울 수 있습니다.
- **단원 정하기**: 연습 모드는 학생이 단원 카드로 고릅니다. 수업 참가는 교사 화면의 "이 채널 단원"에서 채널마다 정하고(바꾸면 그 채널은 새 수업으로 시작), 학생은 채널 → 팀 → 이름 3단계로 들어옵니다.

- **상자 9개 × 하·중·상 = 27문항**: 게임의 상자 N번 = 교사 화면·형성평가지·CSV의 N번으로 서로 연결됩니다.
- **답 형식**: 숫자(2√5, 1/2, π/2도 됨) · 오지선다 · 고르기 · 벡터식(예: `-a+2b`)
- **협업**: `협업: 예`인 상자(3·4번 방)의 상 난이도는 같은 팀 2명이 가까이에서 함께 열어야 시작돼요. 한 명은 조건 ㉠, 다른 한 명은 조건 ㉡만 보고 채팅으로 알려 주며 풀고, 한 명이 맞히면 둘 다 해결됩니다. 1분을 기다려도 짝이 없으면 혼자 풀기(두 조건, 중 배점)를 고를 수 있고, 연습 모드에서는 처음부터 두 조건이 다 보입니다.
- **정답은 서버에만**: md 파일은 서버 코드에 묶여 들어가고, 학생 화면에는 정답과 협업 조건을 빼고 보냅니다.
- **풀이 시간**: 문제를 처음 연 때부터 맞힐 때까지 기록해 교사 화면(학생 이름을 누르면)·CSV·학생 결과 화면에 보여 줍니다.
- **팀 문 열림**: 같은 팀(2명 이상)의 2/3 이상이 문을 열면 그 팀 전체에게 문이 열립니다.
- **교사용 출력**: 교사 화면 위 🖨️ 버튼 → 난이도를 골라 형성평가 문제지·답지, 핵심 카드, 교사용 해설집을 새 창(미리보기)으로 열고 "🖨️ 인쇄 / PDF로 저장"을 누릅니다. 팝업이 막히면 같은 화면 안에서 인쇄합니다.
- **학생 출력**: 수업에서 모든 상자를 풀어 탈출하면, 팀원이 아직 풀고 있어도 결과 창에 "🗂️ 나의 풀이 기록"·오답 정리·형성평가 PDF 버튼이 나옵니다(이때 서버는 그 학생이 푼 난이도의 정답만 보냅니다).
- **중간관리자**: 채널 비밀번호(예: 1채널 비밀번호)로 교사 화면에 들어가면 자기 채널만 열립니다. 전체 관리자 비밀번호는 모든 채널이 열립니다.
- **움직이는 그림**: 레벨마다 `그림:` 줄로 직접 조작하는 그림을 붙입니다. `평면` 또는 `공간` 다음에 `이름=값`을 띄어 씁니다.
  - 정의: 소문자는 벡터·조절기(`a=(2,1)`), 대문자는 점(`A=(0,0)`), `AB`는 B−A, `a@P`는 시작점
  - 설정: `범위` `끌기=A,b` `슬라이더=m,-3,3,0.5` `보기=이름표:식;식` `화살표` `선분` `다각형` `직선=P,u` `원` `평면=n,d` `구=C,r` `직육면체=w,d,h` `자취` `숨김`
  - 보기 이름표에 띄어쓰기는 `_`로 씁니다(`보기=두_직선의_각:각선(u,v)`). `각`·`각선` 값은 도(°)로 보여 줍니다.
  - `조작:` 줄은 그림 위 안내 문장입니다. 내장 도구(`hex`, `square`, `collinear` …)나 그림 주소도 쓸 수 있고, `그림: 없음`이면 그림을 붙이지 않습니다.
- **합답형 [보기]**: 문제 문장에 `\n\n[보기]\nㄱ. …\nㄴ. …`로 쓰면 게임과 인쇄물 모두에서 ㄱ·ㄴ·ㄷ이 한 줄씩 상자에 들어갑니다. 그림의 `보기=`에 ㄱ·ㄴ·ㄷ 양쪽 값을 띄워 학생이 조작하며 확인하게 합니다.
- **줄바꿈**: 문제 문장의 `\n`은 줄바꿈입니다. 조건·정의·질문을 한 줄씩 나누어 씁니다(예: `정육각형 ABCDEF에서\n세 대각선의 교점을 O라 하자.\n…를 구하시오.`).
- **수식 자동 변환**: `$…$`를 쓰지 않아도 글 속의 수식(`|[AB]|`, `√5`, `60°`, `{a}·{b}`, `ABCD-EFGH` …)을 찾아 MathJax로 바꿉니다. `test/mathjax_format.test.js`가 모든 문항·힌트·카드에서 수식 밖에 남은 기호가 없는지 검사합니다.
- **글씨**: 문제 문장은 명조체(함초롬바탕·한컴바탕이 있으면 그것, 없으면 나눔명조)로 크게 보여 줍니다.
- `npm test`가 모든 문항을 채점기로 점검하고(정답은 맞게, 오답은 틀리게), `test/set_geo_3_1.test.js`가 3-1 정답 27개를 좌표 계산으로 다시 구합니다.

## 수업 진행

학생은 첫 화면에서 **TOUCH TO START**를 누른 뒤 카드 하나를 고르고 이름을 적습니다. 방 코드는 없습니다.

| | 🎯 연습 모드 | 🏫 수업 참가 |
|---|---|---|
| 언제 | 아무 때나 바로 시작 | 선생님이 시작 비밀번호로 시작 |
| 친구 | 보이지 않음 | 반 전체가 같은 유적에서 함께 |
| 랭킹·유물 팝업 | 없음 | 있음 |
| 기록 | 나만 이어서 하기, '↺ 처음부터'로 다시 | 교사 집계 화면과 구글 시트에 남음 |

수업 순서:

1. 반이 바뀌었다면 교사 집계 화면(`/teacher`, 교사 비밀번호)에서 **CSV 내려받기**로 이전 반 기록을 저장한 뒤 **새 수업 시작 (기록 지우기)**를 누릅니다.
2. 학생은 **수업 참가** 카드를 고르고 이름(예: `5번 홍길동`)을 적어 들어옵니다. 시작 전에는 돌아다닐 수만 있습니다.
3. 선생님은 학생 화면(수업 참가의 이름 적기 창 아래, 또는 유적 위쪽 안내 띠)의 **🔑 선생님: 수업 탐험 시작**을 누르고 시작 비밀번호를 넣습니다. 그러면 모든 학생의 상자와 장애물이 열립니다.
4. 교사 집계 화면에서 다음을 실시간으로 봅니다.
   - 문제별: 문제 문장과 정답, 도전·정답 인원, 첫 시도 정답률(50% 미만은 빨간색), 자주 나온 오답
   - 학생별: 순위·점수, 맞힌 문제 수, 들어온 시각과 탈출 시각, 현재 위치, 문제별 결과. 이름을 누르면 문제마다 몇 번 만에 맞혔는지, 힌트를 봤는지, 어떤 오답을 냈는지 펼쳐집니다.

조작: WASD·방향키 이동 · `E` 열기 · `M`/`Tab` 지도 켜기·끄기(🗺️ 버튼도 있음) · `G`/`Space` 사격 · `H`/`왼쪽 Alt` 점프 · `K` 소리. 수학자 수정은 방마다 두 개(가운데, 벽·문 옆)이고, 깨진 수정은 40초 뒤 그 방의 벽·문 옆에 다시 생겨서 학생이 많아도 차례로 수학자 카드를 볼 수 있습니다.

점수는 문제를 맞히면 100점, 힌트 없이 첫 시도에 맞히면 50점 더, 벡터 점프 하나에 20점입니다. 점수가 같으면 먼저 도달한 학생이 앞섭니다(`src/room.js`의 `SCORE`).

- 학생이 새로고침하거나 연결이 끊겨도 진행 상황과 위치가 그대로 이어집니다.
- 한 유적에는 최대 40명까지 들어올 수 있습니다. 두 반이 동시에 쓰면 학생과 협동 집계가 섞이니, 반마다 **새 수업 시작**을 눌러 주세요.
- 마지막 활동 뒤 24시간 동안 아무도 들어오지 않으면 기록이 자동으로 지워집니다. 학생 개인정보는 입력한 이름만 저장합니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
npm install
npm run vendor
npm run dev
```

비밀번호는 프로젝트 폴더의 `.dev.vars` 파일에 적습니다. 이 파일은 git에 올라가지 않습니다. 바꾸면 `npm run dev`를 다시 실행합니다.

```
TEACHER_PASSWORD=전체 관리자 비밀번호(모든 채널의 교사 화면)
CHANNEL_PASSWORDS=채널별 교사 비밀번호(예: 1=1111,1112;2=2222 — 채널=비밀번호를 세미콜론으로, 한 채널에 여럿이면 쉼표로)
START_CODES=수업 탐험 시작 비밀번호(여러 개면 쉼표로, 예: 1111,2222)
```

- 교사 화면: http://127.0.0.1:8787/teacher
- 학생 화면: http://127.0.0.1:8787

`npm run vendor`는 three.js와 MathJax에서 브라우저가 쓰는 파일만 `public/vendor`로 복사합니다. 버전을 바꾼 뒤에도 다시 실행합니다.

이 상태에서는 이 컴퓨터에서만 접속할 수 있습니다. 학생 기기에서 접속하려면 아래처럼 배포해야 합니다.

## 배포 (Cloudflare Workers)

```bash
npx wrangler login
npx wrangler secret put TEACHER_PASSWORD
npx wrangler secret put CHANNEL_PASSWORDS
npx wrangler secret put START_CODES
npm run deploy
```

**자동 배포:** Cloudflare 대시보드의 `go` Worker → Settings → Builds에 이 GitHub 저장소가 연결되어 있어서, `main`에 병합하면 Cloudflare가 `npx wrangler deploy`로 자동 배포합니다. 진행 상황은 Worker의 Deployments 탭에서 봅니다. 아래 명령은 처음 설치할 때나 컴퓨터에서 직접 배포할 때 씁니다.

가운데 세 명령은 배포 서버에서 쓸 비밀번호를 묻습니다. 비밀번호는 공개 저장소의 코드에 적지 않습니다. 교사 비밀번호(TEACHER_PASSWORD, CHANNEL_PASSWORDS)가 하나도 없으면 교사 화면에 들어갈 수 없고, START_CODES가 없으면 학생 화면에서 수업 탐험을 시작할 수 없습니다. 하이픈과 띄어쓰기는 무시하므로 `12-34`를 입력해도 `1234`로 들어갑니다.

**중간관리자(채널 교사) 비밀번호와 사용 기간:** 전체 관리자 비밀번호(TEACHER_PASSWORD)로 교사 화면에 들어가면 **🛡️ 중간관리자 관리** 창이 보입니다. 여기서 채널마다 중간관리자 비밀번호를 바꾸고(쉼표로 여러 개) 사용 기간(시작일·종료일, 한국 날짜, 그날 포함)을 정합니다. 화면에서 정한 비밀번호는 그 채널의 CHANNEL_PASSWORDS를 대신하고, '비밀번호 초기화'를 누르면 비밀 값으로 돌아갑니다. 기간 밖에는 그 채널의 중간관리자 로그인과 학생 수업 참가가 막히고, 전체 관리자와 연습 모드는 그대로 됩니다. 설정은 Durable Object `admin:global`에 저장됩니다.

배포하면 `https://go.<계정의 workers.dev 하위 도메인>.workers.dev` 주소가 생깁니다(앞부분 `go`는 `wrangler.toml`의 `name`). 하위 도메인은 Cloudflare 대시보드의 Workers & Pages → Account details → Subdomain에서 바꿀 수 있습니다. Durable Objects(SQLite 저장)를 쓰며, 한 반 규모라면 무료 플랜 한도 안에서 쓸 수 있을 것으로 예상합니다. 다만 실제 요금과 한도는 Cloudflare 요금 안내에서 확인해 주세요.

학생 한 명이 처음 불러오는 양은 약 1.5MB입니다(지형 모델과 three.js 1.2MB, 내 캐릭터 0.25MB). 친구 캐릭터가 화면에 나타나면 캐릭터 종류(12가지)마다 약 0.25MB씩 더 받습니다. 한 번 받은 모델은 다시 받지 않습니다.

## 구글 시트 연동 (선택)

학생이 들어오고 나간 시각과 문제 기록이 구글 시트에 자동으로 쌓입니다. 시트에는 두 탭이 생깁니다.

- **기록**: 시각, 이름, 종류(입장·퇴장·정답·오답·힌트·벡터 점프·탈출·진행 단계·새 수업 시작), 문제, 답, 결과, 시도 횟수
- **학생별 요약**: 순위, 이름, 점수, 맞힌 문제, 힌트, 벡터 점프, 처음 접속, 마지막 접속, 탈출 시각, 접속 중 (새 수업을 시작하면 비워지고, '기록'은 남습니다)

설정 순서:

1. 새 구글 시트를 만들고 **확장 프로그램 → Apps Script**를 엽니다.
2. `google-sheets/Code.gs` 내용을 모두 붙여 넣고, 맨 위 `SECRET`을 아무도 모르는 긴 글자로 바꾼 뒤 저장합니다.
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자 **나**, 액세스 권한 **모든 사용자**로 배포하고 권한을 허용합니다. 나온 웹 앱 주소를 복사합니다.
4. 이 컴퓨터에서 쓸 때는 `.dev.vars`에 두 줄을 더하고 `npm run dev`를 다시 실행합니다.
   ```
   SHEETS_WEBHOOK_URL=복사한 웹 앱 주소
   SHEETS_SECRET=2번에서 정한 글자
   ```
   배포한 서버에서는 `npx wrangler secret put SHEETS_WEBHOOK_URL`, `npx wrangler secret put SHEETS_SECRET`로 넣습니다.

기록은 3초마다 모아서 보내고, 보내지 못하면 잠시 뒤 다시 보냅니다. 설정하지 않으면 이 기능은 꺼져 있고 게임은 그대로 동작합니다. 웹 앱 주소는 누구나 열 수 있지만 SECRET이 맞아야만 시트에 기록됩니다. 학생 이름이 구글 시트에 저장되니, 학교에서 쓰는 계정의 시트를 쓰세요.

## 시험

```bash
npm test
node scripts/loadtest.mjs http://127.0.0.1:8787 28
```

가상 학생 시뮬레이션: 가상 학생 5명이 실력과 속도를 달리해 동시에 탐험하고, 끝나면 랭킹을 출력하고 `results/`에 CSV로 남깁니다. 브라우저로 들어가 있으면 가상 학생이 돌아다니는 모습, 랭킹, 발견 팝업을 볼 수 있습니다.

```bash
node scripts/simulate.mjs http://127.0.0.1:8787 5 3
```

마지막 숫자는 빠르기입니다(1이면 실제 학생 속도, 3이면 약 1분). `--keep`을 붙이면 기존 기록을 지우지 않습니다.

`loadtest.mjs`는 학생 봇 28명이 동시에 접속해 돌아다니며 벡터 점프와 상자 문제를 끝까지 진행합니다. 일부 문제는 일부러 한 번 틀린 뒤 정답을 냅니다. 교사 비밀번호는 `.dev.vars`에서 읽습니다. **시작할 때 '새 수업 시작'을 눌러 기록을 지우므로, 수업 중인 서버에는 쓰지 마세요.**
